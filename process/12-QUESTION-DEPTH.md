# 12 — THE QUESTION RULE. One text, three depths, one question per pass.

Port insight (owner, 2026-10-25), built on analayo 10-MATHEMATICS + 11-STICKINESS.

## The law
Every essay/cluster carries ONE assigned question. The question is spoken,
then a pause, then the gold answers. At each A⊂B⊂C depth the SAME question
is re-posed (rising complexity), and the SAME A clips land unchanged.

```
[question] → [pause = recollect] → [A-clip = the answer]  (retrieval attempt BEFORE the answer)
   A: "What is grace?"            → the glance lands (answer: it happens to you)
   B: re-posed, deeper            → A unchanged + why-method-fails material
   C: re-posed, full              → A+B + the whole apparatus
```

## Why it sticks (three effects, one clip)
1. **Testing/generation effect** — the pause forces an attempt at recall
   before playback; the answer-clip confirms or corrects. Strongest effect
   in the literature (11-STICKINESS: "retrieval practice with teeth").
2. **Retrieval cue** — the question line functions exactly as their
   bells do (2018 cue account); questions are just richer cues than tones.
3. **Spaced revisiting / elaboration** — A re-lands at every depth; each
   pass wraps new complexity around the identical anchor (distributed
   practice "wearing a robe").

## Beat cell (variant of their 5-tuple, same units)
`(question-line, breath+pause, clip, water)` where:
- question-line: HUMAN voice (never Fish — Fish speaks key-lines only)
- pause: 2 breaths = 3.0s (recall window; breath = 1.5s, water = 2.5s,
  unchanged from analayo — everything scored in breath units)
- clip: Bäumer archive, unchanged, sentence-boundary + pause-snapped
- open→close pairs per 11-STICKINESS open-loops: each question marked
  in the manifest with where it gets closed.
